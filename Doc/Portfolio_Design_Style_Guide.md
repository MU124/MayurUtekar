# Portfolio Design Style Guide

## Design Philosophy

Build a modern, premium, and professional portfolio that reflects the
experience of a Senior Full Stack Engineer.

The website should feel clean, fast, and trustworthy rather than flashy.
Every section should have a clear purpose and guide recruiters through
your professional journey.

------------------------------------------------------------------------

# Theme

**Default Theme:** ☀️ Light Mode

Support Dark Mode with a toggle, but keep **Light Mode as the default**.

------------------------------------------------------------------------

# Design Style

-   Modern
-   Minimal
-   Premium
-   Professional
-   Responsive
-   Fast loading
-   Clean typography
-   Plenty of white space
-   Smooth micro-animations

Avoid:

-   Neon effects
-   Heavy gradients
-   Particle backgrounds
-   Auto-playing animations
-   Overly colorful UI
-   Gaming or cyberpunk styles

------------------------------------------------------------------------

# Inspiration

The design should feel similar to products from:

-   Vercel
-   Stripe
-   Linear
-   Notion
-   Raycast
-   GitHub

Simple, elegant, and focused on content.

# Typography

Font Family

-   Inter
-   Geist
-   Manrope

Headings

-   Bold
-   Large
-   High contrast

Body

-   Comfortable reading width
-   18px base size

------------------------------------------------------------------------

# Cards

-   Rounded corners (16px)
-   Soft shadow
-   Thin border
-   Hover elevation
-   Smooth transitions

------------------------------------------------------------------------

# Buttons

Primary

-   Filled brand color
-   Rounded
-   Medium size

Secondary

-   Outline style

Animations

-   Hover scale (subtle)
-   Smooth color transition

------------------------------------------------------------------------

# Icons

Use Lucide Icons throughout the website.

Avoid mixing multiple icon libraries.

------------------------------------------------------------------------

# Images

Use high-quality illustrations, dashboard mockups, code editor
screenshots, or abstract development visuals.

Avoid stock photos and selfies.

------------------------------------------------------------------------

# Animations

Use Framer Motion.

Recommended:

-   Fade In
-   Fade Up
-   Section Reveal
-   Card Hover
-   Smooth Scroll

Avoid excessive animation.

------------------------------------------------------------------------

# Responsive Design

Desktop First

Support:

-   Desktop
-   Laptop
-   Tablet
-   Mobile

------------------------------------------------------------------------

# Accessibility

-   WCAG friendly colors
-   Keyboard navigation
-   Visible focus states
-   Proper heading hierarchy
-   Alt text for images

------------------------------------------------------------------------

------------------------------------------------------------------------

# Overall Goal

Create a portfolio that immediately communicates professionalism,
technical expertise, and enterprise experience. Recruiters should be
able to understand your background within the first 30 seconds while
enjoying a clean, modern browsing experience.
